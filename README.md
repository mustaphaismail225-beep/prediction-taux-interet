# Prédiction du taux d'intérêt d'un prêt bancaire

Projet final du Bootcamp Data Scientist GoMyCode – Mustapha Ismail

## Objectif
Prédire le taux d'intérêt d'un prêt à partir du profil de l'emprunteur, avec un modèle de régression.

## Données
Prêts Lending Club (Kaggle) : 396 030 prêts et 27 variables.
Les données ne sont pas incluses dans ce dépôt (taille de 100 Mo). Source : [LIEN_KAGGLE](https://www.kaggle.com/datasets/sahilnbajaj/lending-club-loan-data?select=lending_club_loan_two.csv)
